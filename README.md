## О проекте

**AI Robotic Owl** — роботизированная модель совы с ИИ: голосовой ассистент с характером, который слышит, видит, говорит и двигается. Проект объединяет три независимые, но тесно связанные части — 3D-печатный корпус, прошивку контроллера и AI-сервер.

## 📁 Структура репозитория

```
ai-robotic-owl/
├── AI-Robot-Server/          # Серверная часть: WebSocket-панель, LLM, STT, TTS
├── 3d-model-for-owl/         # 3D-модели корпуса для печати (Fusion 360 + STL)

```

## 🧠 Компоненты

### [`AI-Robot-Server/`](./AI-Robot-Server)

Голосовой AI-мозг робота: принимает аудио/видео с ESP32-S3 по WebSocket, распознаёт речь, генерирует ответы персонажа через LLM, синтезирует голос и рассчитывает позы сервоприводов — плюс веб-панель для мониторинга и ручного управления.

**Стек:** Python, FastAPI, WebSocket, Uvicorn · llama-cpp-python, ster-whisper, Silero, edge-tts · YOLOv8, MediaPipe, OpenCV · Qdrant

Полное описание архитектуры, API и запуска — в [`AI-Robot-Server/README.md`](./AI-Robot-Server/README.md).

### [`3d-model-for-owl/`](./3d-model-for-owl)

Набор 3D-моделей корпуса для FDM-печати: голова, тело, крылья, хвост, ноги — каждая деталь в отдельном боксе для удобства печати и сборки.

```
├── fusion/               # Исходники Fusion 360 (.f3d)
│   ├── head.f3d
│   ├── body.f3d
│   ├── wing box.f3d
│   ├── wings.f3d
│   ├── tail box.f3d
│   ├── tail.f3d
│   ├── leg box.f3d
│   └── legs.f3d
└── stl/                  # Готовые к печати STL по тем же узлам
    ├── head/...
    ├── body/...
    ├── wing box/...
    ├── wings/...
    ├── tail box/...
    ├── tail/...
    ├── leg box/...
    └── legs/...
```

**Материалs:** PLA/PETG

### [`arduino-owl-model/`](./arduino-owl-model)

Прошивка контроллера **ESP32-S3**: держит WebSocket-соединение с сервером, стримит аудио с микрофона и видео с камеры, воспроизводит голос через динамик, отрабатывает команды на 18 сервоприводов и управляет LED-подсветкой подставки.

**Особенности:**

- Управление **18 сервоприводами** с плавной интерполяцией движений
- Захват и стрим кадров с камеры (адаптивный FPS в зависимости от того, есть ли лицо в кадре)
- Захват и стрим аудио с микрофона, воспроизведение ответов на динамик
- Автопереподключение к Wi-Fi и WebSocket-серверу с heartbeat

## 🔧 Аппаратная платформа

| Компонент             | Спецификация                                                                    |
| --------------------- | ------------------------------------------------------------------------------- |
| Микроконтроллер       | **ESP32-S3** (Wi-Fi, PSRAM)                                                     |
| Драйвер сервоприводов | PCA9685, 16-канальный, I2C (адрес `0x40`)                                       |
| Сервоприводы          | 18× SG90 / MG90S — 16 через PCA9685 + 2 напрямую с ESP32-S3 (крен головы, клюв) |
| Микрофон              | INMP441, цифровой, шина I2S                                                     |
| Динамик               | 4 Ом / 3 Вт + усилитель MAX98357A, I2S                                          |
| Камера                | OV2640                                                                          |
| Подсветка             | Адресная LED-лента (подставка)                                                  |
| Питание сервоприводов | Внешний BEC 5V, 6A+ (отдельно от логики ESP32)                                  |

> Полная распиновка I2C/I2S/камеры и таблица всех 18 индексов сервоприводов — в [`AI-Robot-Server/README.md`](./AI-Robot-Server/README.md#аппаратная-часть).

## 🚀 Быстрый старт

### 1. Аппаратная сборка

1. Распечатайте детали из [`3d-model-for-owl/stl`](./3d-model-for-owl/stl).
2. Установите сервоприводы в корпус согласно узлам сборки.
3. Подключите PCA9685 к ESP32-S3 по I2C и разместите микрофон, камеру и динамик по месту.
4. Обеспечьте отдельное питание 5V для сервоприводов с общей землёй с ESP32.

### 2. Прошивка контроллера

```bash
cd arduino-owl-model
# Откройте проект в Arduino IDE / PlatformIO
# Установите библиотеки: Adafruit PWM Servo Driver, ESP32Servo, ArduinoJson
# Выберите плату: ESP32S3 Dev Module
# Загрузите прошивку
```

### 3. Запуск AI-сервера

```bash
cd AI-Robot-Server
pip install -r requirements.txt
python websocket_server.py
```

Панель управления будет доступна по адресу `http://localhost:8765/panel`. Подробности — в README сервера.
