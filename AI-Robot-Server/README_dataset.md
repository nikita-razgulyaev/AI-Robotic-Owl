# 📚 Датасет для Fine-tuning Сорена

## Структура

```
datasets/
├── raw/                          ← книги, фильм (исходники)
├── curated_v1.jsonl              ← 200 ручных примеров
├── curated_v2.jsonl              ← 600 сгенерированных примеров
└── final_800.jsonl               ← финал для обучения
```

## Формат

Каждая строка — JSON с массивом `messages` в формате Qwen chat:

```json
{
    "messages": [
        { "role": "system", "content": "Ты — Сорен..." },
        { "role": "user", "content": "Привет, Сорен!" },
        { "role": "assistant", "content": "Приветствую, друг..." }
    ]
}
```

## 7 блоков датасета

| Блок                   | Примеры | Что даёт                |
| ---------------------- | ------- | ----------------------- |
| Приветствия/общие      | 100     | Простые ответы без мира |
| Философия              | 200     | Принципы в действии     |
| Эмоциональные триггеры | 150     | Клудд, потери — глубина |
| Вопросы о мире         | 150     | Факты через эмоции      |
| Советы                 | 150     | Практическая мудрость   |
| Технические аналогии   | 100     | Перевод в мир сов       |
| Запретные темы         | 50      | Сохранение персонажа    |

## Разнообразие ответов

Каждый вопрос имеет:

- **5-10 вариантов** ответа
- **Слоты**: [попутный/благоприятный/тихий]
- **Эмоции**: 1 вопрос × 3-5 эмоций
- **Контекст**: 1 вопрос × разные ситуации

## Temperature и repeat_penalty

```
Temperature: 0.6-0.7
Repeat penalty: 1.15
```

Это даёт живые, неповторяющиеся ответы.

## Как добавить свои примеры

1. Открой `curated_v1.jsonl`
2. Перепиши ответы Сорена под свой стиль
3. Добавь новые пары вопрос-ответ
4. Запусти `prepare_dataset.py` для генерации `final_800.jsonl`
